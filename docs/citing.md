# Citing

If dfwb helps your work, please consider citing it. There is no DOI or archived release yet --
cite the software directly, from [`CITATION.cff`](https://github.com/dfwb-research/deepfake-workbench/blob/main/CITATION.cff)
in the repository (GitHub's own "Cite this repository" button on the repository page reads the
same file):

```bibtex
@software{collins_deepfake_workbench,
  author  = {Collins, Luke},
  title   = {Deepfake Workbench},
  url     = {https://github.com/dfwb-research/deepfake-workbench},
  license = {MIT}
}
```

This page, and `CITATION.cff` itself, will gain a DOI once a release is archived (for example
through Zenodo); until then, cite the repository URL and, where your venue wants one, the commit
or tag you actually used.

## Related projects

If you also use [`dfwb-protocols`](ecosystem.md#dfwb-protocols) or a package from
[`dfwb-torch`](ecosystem.md#dfwb-torch), cite that project too, from its own `CITATION.cff` --
each is released and versioned independently of dfwb itself.
